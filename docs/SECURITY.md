## 2. Secrets Management & Environment Isolation

1. **Zero Committed Secrets**:
   - No API keys, database credentials, or private tokens are committed to source control.
   - All `.env`, `.env.local`, and `*.env` files are strictly excluded via `.gitignore`.
2. **Environment Variable Injection**:
   - `ANTHROPIC_API_KEY`, `DATABASE_URL`, `VECTOR_DB_PATH`, and `BACKEND_CORS_ORIGINS` are dynamically loaded via `pydantic-settings` at runtime.
   - The application fails fast on startup if required credentials or models are missing.

---

## 3. Input Validation & Attack Surface Reduction

| Channel | Security Control | Enforcement Mechanism |
|---|---|---|
| **Audio File Upload** | 25 MB Maximum Payload Cap | `HTTP 413 Content Too Large` enforced via stream-length tracker (`backend/api/upload.py`) |
| **MIME / Content-Type** | Whitelist: `.wav`, `.mp3`, `.m4a`, `.mp4` (`audio/wav`, `audio/mpeg`, etc.) | `HTTP 400 Bad Request` on unapproved extensions or binary executables |
| **Audio Chunk Streaming** | 16 kHz Mono PCM16 bounds checking | Buffer sliding window capped at 50 max windows to prevent memory exhaustion (`backend/api/stream.py`) |
| **Patient Identifiers** | Length-capped ($250\text{ chars}$) & ASCII sanitization | `sanitize_user_text` in `backend/core/security.py` |

## 4. Prompt Injection Defenses for RAG & Clinical Synthesis

Large Language Model (LLM) decision support synthesis pipelines are protected by multi-layer input sanitization:

1. **Adversarial Pattern Redaction**:
   - User-influenced text (such as patient identifiers, free-text clinical notes, or task metadata) is scanned against regex filter rules (`ADVERSARIAL_PROMPT_PATTERNS`).
   - Patterns matching prompt override attempts (e.g., `"Ignore previous instructions"`, `"SYSTEM:"`, `"[/PROMPT]"`, or `<script>` tags) are automatically redacted to `[REDACTED_INJECTION_ATTEMPT]`.
2. **Delimiter Tampering Protection**:
   - System prompts isolate user inputs within clearly delimited tags (`[NUMERIC_VALUES]`, `[RETRIEVED_CHUNKS]`, `[SIMILARITY_RESULTS]`).
   - Any raw text containing bracketed prompt delimiters is stripped prior to template assembly.

## 5. Automated LLM Output Schema & Disclaimer Validation

Output generated by the RAG LLM is never passed directly to the client without passing through strict structural verification (`backend/rag/output_validator.py`):

1. **Exact Numeric Value Verification**:
   - The calibrated probability and confidence scores generated in the narrative must match the inference engine's numeric outputs within strict $\epsilon$-tolerances.
2. **Mandatory Disclaimer Verification**:
   - The report must contain the exact, non-dismissible regulatory disclaimer:
     > `"THIS IS AN AI‑BASED SCREENING/DECISION‑SUPPORT OUTPUT, NOT A STANDALONE DIAGNOSIS."`
3. **Degraded Numeric Fallback Gate**:
   - If LLM generation or output validation fails after one automated correction retry, the backend falls back to **Degraded Mode** (`HTTP 500` with detail `"Report generation degraded – numeric results only."`), ensuring no hallucinated or unvalidated claims reach clinicians.

## 6. Audio Retention & Data Minimization Policy

To adhere to data minimization principles (GDPR Article 5(1)(c) and HIPAA minimum necessary standard):

1. **Configurable Retention Window**:
   - The default retention window for temporary audio files is set to **30 days** (configurable via `AUDIO_RETENTION_DAYS`).
2. **Automated File Cleanup Job**:
   - `cleanup_expired_audio_files(storage_dir, retention_days)` crawls audio storage directories, identifies files exceeding the retention window, and securely deletes them from the filesystem.
   - Deletions are logged to the audit trail as `AUDIO_RETENTION_PURGE` events.

## 8. Network & CORS Security

1. **Strict CORS Whitelist**:
   - `CORSMiddleware` restricts cross-origin resource sharing to explicitly allowed origins defined in `BACKEND_CORS_ORIGINS` (e.g. `http://localhost:3000`).
   - Unlisted third-party domains do not receive cross-origin permissions.
2. **Reverse Proxy Configuration**:
   - Vite development and production reverse proxies (`/api` and `/ws`) isolate backend networking behind single-origin gateways.
