# Respiratory / Clinical Screening & Decision-Support System

## Description
This project is an AI-assisted screening and clinical decision-support system designed to analyze patient data, audio signals (such as respiratory recordings), and clinical records to provide assistive insights to healthcare professionals.

## Medical & Regulatory Disclaimer
> [!WARNING]
> **DISCLAIMER: SCREENING AND DECISION-SUPPORT TOOL ONLY — NOT A DIAGNOSTIC DEVICE**
> This software is intended strictly for research, screening, and clinical decision-support purposes. It is **NOT** a medical diagnostic device and should not be used as a sole basis for clinical diagnosis, treatment decisions, or emergency medical triage. All outputs, metrics, and recommendations must be reviewed and verified by qualified medical professionals.
